# Mask size-run registry — Fisher & Paykel, ResMed, Philips Respironics

The compiled result of verifying **every size run** the catalog carries
from the three largest manufacturers against manufacturer-grade sources.
This is the per-model evidence behind migrations
[`0511`](../lib/resupply-db/migrations/0511_mask_fit_band_conventions.sql)
and [`0512`](../lib/resupply-db/migrations/0512_mask_size_run_corrections.sql)
and the legacy-catalog rewrite; the geometry story is in
[`mask-fit-band-audit-2026-08-21.md`](./mask-fit-band-audit-2026-08-21.md).

**Evidence bar.** A run was only changed on (a) a manufacturer-hosted
document or manufacturer page, or (b) two independent, consistent
sources, preferably with per-size SKUs. "Confirmed" below means the
seeded run met that bar unchanged. Where the two catalogs both carry a
model, the DB catalog (`mask_models` / `mask_size_variants`) and the
legacy array (`maskCatalog.ts`) now agree.

## Where the corrections were applied

Every "0511"/"0512" row above changed **both** catalogs:

1. **DB catalog** (`resupply.mask_size_variants`) — renames in place so
   row UUIDs survive; sizes the manufacturer never shipped retired (not
   deleted — `fit_sessions` holds plain foreign keys); missing sizes
   inserted with bands derived on the same rules as 0511; the fabricated
   DreamWear Full Face Gel retired at the model level (`catalog-store`
   loads only current models, so it is structurally unrecommendable).
2. **Legacy storefront catalog** (`maskCatalog.ts`, live behind
   `/api/recommend` and `/api/masks`) — same runs, and every `fitRanges`
   block replaced with the canonical-face ±18% envelope on the
   pipeline's axes (see the header comment in that file and
   `maskCatalog.conventions.test.ts` for why uniform ranges are the
   honest encoding under that engine's semantics).

Pinned by `lib/fitting/catalog-bands.test.ts` (DB) and
`data/maskCatalog.conventions.test.ts` (legacy).

## Notes and residual uncertainty

- **N20 for Her / F20 for Her / P10 for Her / Mirage FX for Her** are
  packaging variants sharing cushions with the base model; their seeded
  runs match the "for Her" packs and were left as-is.
- **FitLife XL**: two retailers describe the mask in S/L/XL while
  Philips' own (older) page mentions S/L headgear only. XL was added on
  the retailer evidence; if Philips confirms S/L only, drop the XL row.
- **Quattro Air / AirFit F10 XS**: the XS cushion is shared across the
  Quattro Air / F10 families (sold for the "for Her" variants, fits the
  XS/S frame). Included because the cushion is orderable and
  cross-compatible.
- **PerformaTrak SE** sizes are hospital-channel; S/M/L kept on one
  source plus Philips' "three sizes" copy.
- Non-Big-3 manufacturers (React Health, Sleepnet, Circadiance, Bleep,
  Hans Rudolph, Inogen, Rain8) were **not** re-verified in this pass —
  their bands were re-derived on the correct axis by 0511, but their
  size runs still carry seed provenance.
